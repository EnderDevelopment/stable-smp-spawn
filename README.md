# StableSMPSpawn

StableSMPSpawn is a Minecraft Paper plugin designed to enhance the spawn experience on your server. It includes features like teleporting players to spawn, setting spawn locations, protecting spawn areas, disabling PvP in spawn, and more. This plugin is perfect for server administrators looking to manage and protect their server's spawn area effectively.

## Install

1. Download the `StableSMPSpawn.jar` file from the [GitHub releases page](https://github.com/EnderDevelopment/StableSMPSpawn/releases).
2. Place the `StableSMPSpawn.jar` file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. **Set Spawn Location**: Use the command `/stablesmp setspawn` to set the spawn location to your current position. You need OP permissions to use this command.
2. **Teleport to Spawn**: Use the command `/spawn` to teleport to the spawn location.
3. **Reload Configuration**: Use the command `/stablesmp reload` to reload the plugin configuration. You need OP permissions to use this command.
4. **Spawn Protection**: The plugin protects the spawn area from block breaking and placing.
5. **Disable PvP in Spawn**: PvP is disabled within a configurable 45-block radius of the spawn.
6. **Respawn Handling**: Players without a bed or respawn anchor will respawn at the server spawn when they die.
7. **Gold-Colored Messages**: The plugin uses gold-colored messages for all its outputs.
